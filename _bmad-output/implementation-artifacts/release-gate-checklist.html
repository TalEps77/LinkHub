LinkHub — Local Verification & Release-Gate Checklist

Why this exists. LinkHub's implementation is authored in a Linux/web environment with no Xcode/swiftc (per CLAUDE.md). Every story's code + tests are written to Swift 6 strict-concurrency correctness by review, but the actual build, test run, and hardware-dependent verification must execute on a Mac with Xcode 16. This is the single source of truth for those deferred gates. A story is "done" in the sprint tracker when code + tests + review are complete; it is release-verified only when the relevant rows below pass on real hardware.

A. Build & test (after every story; required before release)

xcodegen generate
xcodebuild -project LinkHub.xcodeproj -scheme LinkHub -configuration Debug build      # zero warnings (NFR33)
xcodebuild -project LinkHub.xcodeproj -scheme LinkHub -configuration Release build    # zero strict-concurrency warnings
xcodebuild -project LinkHub.xcodeproj -scheme LinkHub -configuration Debug test       # all tests pass
  • xcodegen generate picks up all new files via recursive path: globs — verify post-generation.
  • Debug build: zero warnings (NFR33).
  • Release build: zero Swift 6 strict-concurrency warnings/errors. The Story 1.1 Release "isn't code signed but requires entitlements" warning is expected until Story 4.4.
  • Full test suite green (no regressions across epics).

Highest-risk compile spots flagged during web authoring (check first if build fails):

  • PopoverController DismissBox + \.dismissPopover @MainActor () -> Void typing (Story 1.5).
  • WiFiSection.wifiPowerBinding setter Task capture (Story 2.5).
  • EthernetMonitor @convention(c) SCDynamicStore callback + Unmanaged context + Sendable snapshot hop (Story 3.1).
  • WiFiRow @ViewBuilder body if/else context-menu attach returns one some View (Story 2.6).

B. Accessibility — VoiceOver (Cmd+F5)

  • Each WiFiRow reads the UX-DR22 combined label; decorative glyphs not separately announced (1.4/1.6).
  • Menu-bar icon reads UX-DR24 labels (1.6).
  • Announcements: disconnect, power on/off, grant-after-denial, connect, Ethernet in/out (1.5/1.6/2.3/3.5).
  • EthernetRow reads UX-DR23 by state; state dots accessibilityHidden (3.6).

D. Functional — Wi-Fi (LINKHUB_MOCK_WIFI=1 where needed)

  • Scan-on-open; connected row first with checkmark + semibold (1.4).
  • Location denied → LocationDeniedView; Settings handoff; grant auto-retries without restart (1.5).
  • Open single-tap connect; WPA inline password; wrong password caption, field cleared, stays expanded (2.3).
  • "Other Network…" hidden-network join (in-popover) (2.4).
  • Power toggle flips real radio; off → "Wi-Fi: Off", list hidden, association dropped (2.5).
  • Captive connect → default browser opens captive.apple.com (2.5).
  • Right-click known network → Forget / Open in Settings; unknown rows no menu; Forget clears Keychain (2.6).
  • Keychain: persist only on success; re-join no re-prompt (2.2/2.3).

E. Functional — Ethernet (Epic 3; needs adapter)

  • Cable in → cable.connector within 1.5 s; EthernetSection promoted above Wi-Fi (3.3/3.4).
  • Four states render with dot + text label (3.3).
  • Cable out → 1.5 s grace before hide; transient unplug no flicker (3.5).
  • Multiple interfaces: top 2 inline + "+ N more in Settings…" overflow → Network Settings (3.6).
  • Survives sleep/wake, router reset, dock reconnect, VPN toggle (3.5, NFR11).

F. Performance / reliability — Instruments (Apple Silicon)

  • Popover first paint ≤200 ms cold / ≤100 ms warm (NFR2) (1.4).
  • Idle 60 s: ≤80 MB resident, ≤0.5% avg CPU (FR48/FR49) — Epic 1 baseline (1.6).
  • Epic 2 regression: same budget after 10 connect/disconnect/forget cycles (2.6).
  • Epic 3 regression: same budget + 1-hour zero LinkHub leaks (3.6, NFR8).
  • Story 4.7 final pass: 1-hour Allocations + Leaks + Time Profiler; ≤80 MB / ≤0.5% / zero leaks; ≤±5% vs baselines — verification-only; cannot run without hardware.
